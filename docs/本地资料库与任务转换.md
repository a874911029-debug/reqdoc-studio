# 本地资料库与任务转换

V8.0.18 新增本地资料库入口，提供总文档库、项目、文档三级浏览。工作文档、整理文档及历史记录文档均可在库中打开和删除。

## 资料库随软件保存

Windows 正式版默认使用 ReqDocStudio.exe 所在文件夹中的「总文档库」。第一次启动会复制已存在的 V8 资料库，并校验数据库。项目、文档、任务、图片及整理规则一起迁移。

移动软件时复制整个软件文件夹，其中包括总文档库。更新程序沿用原有三文件更新方式。开发环境和显式指定 REQDOC_V8_DATA 的测试会话仍可使用指定文件库。

资料库界面按项目和文档呈现层级，底层数据库和素材由软件管理。旧资料在迁移后仍可作为迁移核对来源。软件目录需要具备写入权限。

## 文档类型和删除

| 类型 | 用途 | 删除入口 |
| --- | --- | --- |
| 工作文档 | 项目下的主工作内容与任务清单 | 资料库中选中后删除，或文档编辑区的删除当前文档 |
| 整理文档 | 一键整理另存的结果 | 资料库中选中后删除，或文档编辑区的删除整理文档 |
| 历史记录文档 | 导入文件的历史资料及其编辑副本 | 资料库中选中后删除，或文档编辑区的删除历史记录 |

删除历史记录会移除归档原文件、该记录的编辑内容和任务同步关联。已引用的图片继续作为文档素材保存，已有任务在任务列表中独立管理。删除动作需要在软件中确认。

文件删除与数据库变更使用恢复日志协调。未提交的删除会恢复原文件，已经提交的删除会完成临时文件清理。

## 任务转换预览

点击转成任务，先选择识别方式并预览。

- 自动识别包含表格逐行识别。整理文档会沿用整理后的主题及条目，来源行作为整理元数据处理。
- 按整理主题逐条会使用一键整理中保存的关键词规则。
- 按章节汇总会将同一章节的内容汇成一个任务。

预览中可勾选、全选或清空新条目，并编辑标题、主题分组及正文。点击应用修改或切换条目时保存预览内的编辑，最后点击确认生成任务。取消预览会放弃本次候选任务。

已经关联的条目显示已关联。相同识别方式再次转换会沿用关联，更换识别方式时仅复用完全相同的条目。改变拆分方式产生的新条目需在预览中核对。

每次最多识别 500 条任务。任务生成、来源关联和识别设置在同一数据库事务中提交。
