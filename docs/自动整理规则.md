# ReqDoc 自动整理规则

V8.0.17 对当前工作文档的手写正文和选中的导入副本做本地整理。结果先预览，确认后另存为可编辑文档。

在文档编辑工具栏选择「删除当前副本」，可删除当前导入副本或整理结果。确认后移除该副本的编辑内容、任务同步关联和下拉列表入口，切换文档或重新启动后保持删除状态。原件归档及已生成任务分别管理。再次导入相同文件会创建一份新副本。

## 可选择的整理方式

| 方式 | 实际处理 |
| --- | --- |
| 按内容主题归类 | 使用关键词规则、原文章节、行内主题和正文相似词组归类。无法可靠归类的内容进入待归类。 |
| 按原文章节归并 | 统一章节编号和少量常见别名，保留父章节语境，在同一章节内归并资料。 |
| 按资料来源保序 | 每份资料保持原有内容块顺序，适合操作步骤、时间线和上下文联系较强的材料。 |

## 分块与保留内容

- 识别 Markdown 标题、Setext 标题、中文章节和单独的主题标签。
- 普通正文按段落及完整句子的换行拆分。同一行中明确出现新的主题标签时可以继续拆分。
- 表格、代码围栏、缩进代码、有序步骤和嵌套列表作为完整内容块处理。
- 图片与链接地址保留。跨文档重复的 Markdown 引用标签及脚注标签增加来源标识，避免引用串到另一份文档。
- 每个条目记录来源名称、行号和原章节。合并重复时同时保留全部来源。

## 关键词规则

每行一个主题，等号右侧列出关键词或同义表达。主题的排列顺序决定结果的排列顺序。空规则使用自动分组。

```text
灯光 = 灯光, 照明, 光照
材质 = 材质, 贴图, 纹理
```

关键词在正文命中计 1 分，在原章节命中计 2 分。英文关键词检查完整词边界。最高分并列时优先保留原章节或明确行内主题，缺少这些依据时放入待归类。

规则与勾选项在成功整理后保存在文件库的 `home/organize-rules.json`。下次打开会恢复。修改规则或所选资料后需要重新整理，才能保存对应结果。

## 相似度和重复

自动分组使用英文词和中文连续 2–4 字片段，去掉常用功能词，对多段共有的片段计算 TF-IDF 权重。先尝试匹配已出现的主题，再以代表内容块进行余弦相似度比较。

分组阈值为 0.28，属于当前版本的工程取值。结果显示提取的共有词组，并标为建议归类。这个方法依赖表面词组重合。同义改写需要关键词规则补充，广泛语义理解仍有局限。

重复合并只处理同一组内完全相同的内容或正文空白差异。代码、表格、列表及保护块使用原文精确比较。数值、标点、大小写、列表缩进和否定表达参与内容保留。

相近内容核对暂时忽略数值和限制词来比较文本模板，阈值为 0.65。候选对会另外比较数值、日期和限制表达，并记录差异。相近内容始终保留各自原文，结果不会据此自动认定哪一项正确。最多列出 200 对核对建议。

## 运行和验收边界

整理在后台执行，支持关闭窗口取消。输入和输出均限制为 20 MB，最多识别 10000 个内容块，超过时提示分批处理。特征提取使用每个长块的前 12000 字，输出保留整块正文。

整理说明列出归类依据、合并数量、待归类数量和相近内容核对。实际资料中的分类正确率仍需要用户反馈验证。整理结果另存时使用现有独立副本机制。

## 借鉴来源及适用范围

- OpenRefine 的文本指纹、近邻比较和候选分桶适合找重复及措辞接近项。ReqDoc 保留标点、数值和否定表达，避免把语义差异当作格式差异。该工具也明确区分句法聚类与语义对齐。[官方说明](https://openrefine.org/docs/technical-reference/clustering-in-depth)
- Unstructured 基于文档元素分块并保留原始元素元数据的方式，适合保护表格、章节和来源联系。ReqDoc 在现有 Markdown 编辑模型中实现对应规则。[官方说明](https://docs.unstructured.io/open-source/core-functionality/chunking)
- scikit-learn 的文档聚类示例使用词袋与 TF-IDF 特征。ReqDoc 采用同类权重思路，以稀疏候选比较适应小型本地应用，并针对中文使用字片段。[官方示例](https://scikit-learn.org/stable/auto_examples/text/plot_document_clustering.html)
- DEVONthink 的分类建议带有置信判断。ReqDoc 对证据不足的段落保留待归类位置。[开发商手册](https://download.devontechnologies.com/download/devonthink/3.9.5/DEVONthink%20Manual.pdf)
